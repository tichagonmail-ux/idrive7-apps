# Goku HUD 0.4.6 — ทดสอบขอบจอจริง

รุ่นทดลองขนาดก่อนลงรายละเอียดภาพอนิเมะใหม่ ใช้ภาพเดิมและขยับเกจออกข้างฝั่งละ 160 px จาก 0.4.5 พร้อมโค้งส่วนหัวหลบมุมบน
ไม่ย่อทั้งภาพ ตัวละคร ฟอนต์ และกล่องเกจยังขนาดเดิม

หลังอัปเดต เปิด Apps > Goku HUD ตั้ง Mode เป็น Instrument cluster และ Cluster design เป็น Goku Performance (full cluster)
เลือก Screen size test (0.4.6):

- Wide art + ruler: ภาพมังกรเดิมที่ขยายระยะวางออกด้านข้าง พร้อมกรอบสี (ค่าเริ่มต้น)
- Ruler only: พื้นเทา กริด และพิกัด สำหรับถ่ายรูปวัดขอบให้ชัด
- Wide art only: ซ่อนกรอบ ดูตำแหน่งภาพอย่างเดียว

กริดช่องละ 100 px จุดกำเนิดอยู่มุมซ้ายบน เส้นพิกัดตรงกับผืนแอป 1920×660 และเว้นแถว BMW y=660…719
กรอบชมพูชิดขอบแอป 2 px / แดงห่างขอบ 20 / ส้ม 40 / ฟ้า 80 / เขียว 120 px
ระยะด้านล่างนับจาก y=660 ไม่ใช่จากขอบแผง 720 px
เส้นที่หายตามมุมโค้งเป็นสิ่งที่ต้องการวัด ไม่ใช่ผลยืนยันว่าขอบนี้พอดีแล้ว

จอดรถแล้วถ่ายเต็มจอ 2 รูป: Ruler only และ Wide art + ruler ให้เห็นกรอบจอจริงกับแถว BMW ด้านล่างด้วย
Mode > Off คืนพื้นที่ให้ BMW

รุ่นนี้ยังใช้ภาพมังกรและตัวละครเดิมสำหรับวัดขอบ ไม่ใช่ภาพคอนเซปต์อนิเมะใหม่ ไม่มีดราก้อนบอลเพิ่มในตัวทดสอบ
บันทึกโปรไฟล์เก่าไว้ ไม่ทับข้อมูลวัดเดิม ตัวทดสอบอยู่ assets/goku-hud/g20-id7-extent-test.json
